# NEOMETO: New Methods (84)

Build a premium, minimal, responsive landing page for a new global brand called NEOMETO.
NEOMETO means “New Method”.
CORE IDEA:
NEOMETO helps people find simple, practical methods for things they want to handle better in their minds and everyday lives.
It is NOT primarily a therapy platform.
It is NOT a diagnosis platform.
It is NOT a meditation app.
The core philosophy is:
Start with the problem, not the diagnosis.
Find a method.
Try it immediately.
Learn what works for you.
BRAND:
Name: NEOMETO
Main tagline: “New Methods for Modern Minds.”
Alternative message: “A better method might be all you need.”
DESIGN:
Create a Scandinavian, premium, extremely clean design.
Use:
Background: #F7F7F2
Primary dark: #101828
Primary accent: #4F6EF7
Light accent: #DCE4FF
Success accent: #65A987
Typography: Inter or Manrope.
Use generous whitespace, large typography, rounded cards and subtle animations.
Do NOT use:
stock photography,
people holding their heads,
brains,
medical imagery,
lotus flowers,
meditation clichés,
generic mental-health imagery.
Instead create subtle abstract visual elements representing thoughts moving from chaos toward structure: dots, lines, particles or shapes becoming organised.
The website must feel more like a modern intelligent product than a healthcare website.
